# Cosmetic Store Seeder

[![EveJS 0.12.9](https://img.shields.io/badge/EveJS-0.12.9-2f6f9f)](https://github.com/V0nCleef/evejs-launcher/releases/tag/v1.0.69)
[![Native only](https://img.shields.io/badge/backend-native--only-6f42c1)](#requirements)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Cosmetic Store Seeder adds permanent ship SKIN licenses and published wearable
character appearance items to the in-game New Eden Store.

The default catalog includes permanent SKIN licenses, eyewear, tattoos,
outerwear, tops, bottoms, footwear, and headwear. Timed SKIN licenses are left
out. Deterministic prices are 25–250 PLEX for SKINs and 5–50 PLEX for apparel.

## Features

- Builds a deterministic cosmetic catalog from the native item data.
- Preserves existing manual offers for the same item.
- Updates offers generated by this mod when the catalog changes.
- Disables removed generated entries instead of deleting them.
- Adds no public checkout or PLEX reward behavior.
- Reconciles the catalog once at startup through the native GameStore.

Prices are generated from the item type ID and priceSeed, so they look varied
but remain stable after restarts and repeated reconciliation.

## Requirements

- Native EveJS 0.12.9
- [EveJS Launcher 1.0.69](https://github.com/V0nCleef/evejs-launcher/releases/tag/v1.0.69) or newer

This mod is native-only. Docker deployments are not supported.

## Installation

1. Copy cosmeticStoreSeeder into the EveJS mods directory.
2. Keep the manifest at mods/cosmeticStoreSeeder/evejs-launcher.mod.json.
3. Enable **Cosmetic Store Seeder** in the EveJS Launcher.
4. Restart the **Game server** and reconnect the client.

The first server startup reconciles the store authority in the local GameStore
database. Back up the GameStore data before enabling the mod.

## Configuration

Edit mods/cosmeticStoreSeeder/config/cosmetics.json while the Game server is
stopped, then restart the Game server.

- enabled: turns catalog reconciliation on or off.
- priceSeed: changes deterministic price assignment for newly created offers.
- priceRanges.skin.min and priceRanges.skin.max: SKIN price range in PLEX.
- priceRanges.apparel.min and priceRanges.apparel.max: apparel price range in PLEX.
- permanentSkinGroupID: item group used to identify permanent SKIN licenses.
- apparelGroupIDs: apparel groups included in the catalog.

The categories and apparelCategoryID values identify native GameStore
categories and normally should not be changed. Existing generated offers are
updated or disabled during reconciliation; they are not removed.

## Updating and removal

Stop the Game server before replacing the mod folder. Keep the existing
manifest directory name, enable the updated version in the Launcher, and
restart the Game server.

Set enabled to false and restart the Game server to stop reconciliation.
Disabling or removing the mod does not delete offers it created; generated
offers remain available for manual cleanup in the GameStore if desired.

## Validation

From the mod directory, run:

```powershell
node test/validate.js
```

The validation is self-contained and does not require a running server.

## Database warning

This mod modifies the local GameStore database. On startup it creates and
reconciles cosmetic store records used by the server. Back up the database
before enabling the mod. Disabling the mod does not automatically remove the
offers it created.
