# Cosmetic Store Seeder

Cosmetic Store Seeder adds permanent ship SKIN licenses and all published
wearable character appearance items to the in-game New Eden Store.

Release: `0.1.0`
Compatibility: EveJS `0.12.9`, native backend, EveJS Launcher manifest schema
version 3.

The default catalog includes:

- Permanent SKIN licenses only. Timed SKIN licenses are left out.
- Eyewear, tattoos, outerwear, tops, bottoms, footwear, and headwear.
- Deterministic PLEX prices: 25–250 PLEX for SKINs and 5–50 PLEX for apparel.

Prices are generated from the item type ID and priceSeed, so they look varied
but remain stable after restarts and repeated reconciliation. Existing manual
offers for the same item are preserved. Offers generated by this mod are
updated when the catalog changes, while removed catalog entries are disabled
instead of deleted. No public checkout or PLEX reward behavior is added.

## Installation

Install `mods/cosmeticStoreSeeder` through the EveJS Launcher, enable it,
restart the Game server, and reconnect the client. The first server startup
reconciles the store authority in the local GameStore database.

To change ranges or the seed, edit config/cosmetics.json. Changing the seed
only affects newly created offers; existing generated offer prices are retained
so a normal restart does not unexpectedly reprice the catalog.

## Configuration

The configuration file is `mods/cosmeticStoreSeeder/config/cosmetics.json`.
Edit it while the Game server is stopped, then restart the Game server for the
changes to take effect.

- `enabled`: turns catalog reconciliation on or off.
- `priceSeed`: changes the deterministic price assignment for newly created
  offers.
- `priceRanges.skin.min` and `priceRanges.skin.max`: minimum and maximum SKIN
  prices in PLEX.
- `priceRanges.apparel.min` and `priceRanges.apparel.max`: minimum and maximum
  apparel prices in PLEX.
- `permanentSkinGroupID`: item group used to identify permanent SKIN licenses.
- `apparelGroupIDs`: apparel groups included in the catalog.

The `categories` and `apparelCategoryID` values identify the native GameStore
categories and normally should not be changed. Existing offers generated by
the mod are updated or disabled during reconciliation; they are not removed.

For a GitHub release, download the versioned ZIP from the repository's
**Releases** page and extract the `cosmeticStoreSeeder` folder directly under
the EveJS `mods` directory. The manifest must remain at:

```text
mods/cosmeticStoreSeeder/evejs-launcher.mod.json
```

Do not extract it into an extra nested directory. Back up the GameStore data
before enabling the mod.

## Updating and removal

Stop the Game server before replacing the mod folder. Keep the existing
manifest directory name, enable the updated version in the Launcher, and
restart the Game server.

Set `enabled` to `false` and restart the Game server to stop reconciliation.
Disabling or removing the mod does not delete the offers it created; generated
offers remain available for manual cleanup in the GameStore if desired.

## Validation

From the mod directory, run:

```powershell
node test/validate.js
```

The validation is self-contained and does not require a running server.

This is a native-only EveJS mod. Docker deployments are not supported.

## What this mod is

Cosmetic Store Seeder populates the in-game New Eden Store with permanent SKIN
licenses and wearable character appearance items using a deterministic catalog
and PLEX price range.

### Database warning

This mod modifies the local GameStore database. On startup it creates and
reconciles the cosmetic store records used by the server. Back up the database
before enabling the mod. Disabling the mod does not automatically remove the
offers it has created.
